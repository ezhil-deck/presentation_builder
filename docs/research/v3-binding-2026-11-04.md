## The library

`packages/templates/data/authored.json` (15 records; byte-identical on a second run). The two statement templates carry a
working-slide header (label + title, mark k / t, title 44 px = 4.1 % H) since the fix round. Authored roles: 45 / 47
agree with `identify()`. Questions left (13): the two authored `device` elements are identified `cut-shape` (a device
needs the brand's or the record's own signature, never a mark); 11 authored categories differ from the kind chain
(cover-slide -> section-slide x 6, cta-slide -> text-slide x 2, quote-slide -> text-slide x 2 / image-text-slide x 1),
because the chain reads deck position and, for the statements, the header text; the binding reads `authoredCategory`.

## Counts

- Bound: **46 of 60** cover / section / cta / quote slides (10 brands x 6). Not bound: slide 25 on every brand (3 quotes;
  a statement template holds one) and the cover of headspace, notion, rukko and stripe (rule 4 below: the brand gives
  the cover its own visual, and the only templates their cover surface qualifies for need a photo the content does not
  give).
- Candidate-level disqualifiers over the 60 slides (one count per template per slide): image:any 38, content: several
  quotes 30, content: a label without an element 30, content: a section number without an element 20, content: the
  slide's own picture without a photo 20, colour-field:light 18, cutout 10, colour-field:dark 10, image:photo-people 9,
  photo-area 9, device:shape 9, device:any 8.
- Rules of the fix round (coordinator, 2026-11-04): (1) a template must have an element for every content field the slide
  carries; (2) a template photo keeps one gutter clear of the brand's boxed decor and the footer (left out under half its
  height); (3) a sample meets an image need only when the brand tags it hero / cover / bleed (product-ui: hero); (4) when
  the brand gives the kind its own visual (an image background variant, a device namedBy / allowedOn the kind) a template
  photo or cut-out comes only from the slide's own image unless the template binds that device; needs weighted (device,
  photo area, text zone, overlay 2; others 1).
- Covers that changed template with rules 3 / 4 (all were cover-panel-photo before): akgmedia -> cover-type-rule (rule 3:
  no tagged sample; rule 4 too: ringsTitle allowed on the cover); bosch, cisco, shopify -> cover-type-rule (rule 4: the
  cover background is the brand image variant hero / heroPhoto / heroVideo); the-ken -> cover-type-rule (rule 3: no
  tagged sample; rule 4 too: heroPhoto); headspace, notion, rukko -> none (rule 4: illustration-family / peekTop /
  cutBlack allowed on the cover); stripe -> none (rule 4: heroRibbon). hdfc-2 keeps cover-device-photo-field (it binds
  the device; score 11). The type-rule covers keep the brand's own cover background (no template photo).
- Statements (slide 26) now bind statement-photo on all 10 brands with the slide title and the quote label in the
  header (score 2; 0 on akgmedia and hdfc-2, which have no avatar component).
